## 1. Try-off / garment extraction (worn image → flat garment)

Shared limitations stated in the literature: TEMU-VTOFF names "disentangling garment features from occlusions and complex poses" and single-category restriction as the failures of prior VTOFF; 2025 inverse-try-on papers say "challenges persist in preserving complex structures, such as logos and printed designs"; the unseen back side is necessarily hallucinated (no paper found that evaluates back-view fidelity → NV). TryOffDiff argues SSIM-type metrics are unreliable and adopts DISTS.

- **TryOffDiff** (arXiv 2411.18350, BMVC'25) — In: person photo (SigLIP-p16-512) → canonical garment. Worn: yes (task). Mech: SD + SigLIP conditioning. Cat: v1 upper (VITON-HD). Code/Lic: rizavelioglu/tryoffdiff; **SSPL** ("not for commercial use unless FULL source open-sourced"; "intended solely for academic research"); weights HF. VRAM: not stated. Ev: A/B.
- **MGT — Multi-Garment Virtual Try-Off** (arXiv 2504.13078) — person photo (+class) → flat garment; TryOffDiffv2Single per DressCode category and TryOffDiffv2Multi. **Only work found that explicitly evaluates two-stage try-off→try-on P2P**: feeding try-off outputs into try-on "reduces unwanted attribute transfer, such as skin color"; P2P pairs published. Downstream try-on model: NV. 20 steps, CFG 2.5. Lic SSPL. Ev: A/B.
- **TryOffAnyone** (arXiv 2412.08573) — worn photo + garment mask → tiled flat cloth. SD1.5 fine-tune, 267M trainable. Cat: upper only. ixarchakos/try-off-anyone; **no LICENSE file** → all rights reserved by default; weights HF. Ev: A.
- **TEMU-VTOFF / Inverse Virtual Try-On** (arXiv 2505.21062, ICLR 2026) — person + bbox/fine mask + VLM caption (Qwen2.5-VL-7B; T5/CLIP/OpenCLIP). Dual-DiT on **SD3-Medium (gated)**, DINOv2 alignment. Cat: upper/lower/full in one model. 768×1024, 28 steps, CFG 2.0. davidelobba/TEMU-VTOFF, **CC BY-NC 4.0**; weights HF. VRAM not stated (SD3-M class). Ev: A/B.
- **RAGDiffusion** (arXiv 2411.19528, ICCV 2025) — hanger/person/chair → flat-lay; retrieval-augmented structure + coarse-to-fine texture. Code NV. Ev: B.
- **IGR** (arXiv 2412.11513) — two garment extractors fused into LDM; claims occlusion robustness. Code NV. Ev: B.
- Unified try-on + try-off: **Voost** (2508.04825; CC BY-NC-SA; base/weights/VRAM not in README; HF demo; P2P not mentioned); **Any2AnyTryon** (2501.15891; FLUX.1-dev LoRA HF loooooong/Any2anyTryon; tags <MODEL>/<GARMENT>/<TARGET>; tasks try-on, garment reconstruction, model generation, try-on in layers; abstract says no masks but README test pipeline requires AutoMasker masks "for repainting"; **no LICENSE**; `--group_offloading`); **One Model for All / Partial Diffusion** (2508.04559; mask-free unified "in any pose"; no code); **Two-Way Garment Transfer** (2508.04551; title only); **OrthoTryOn** (ECCV 2026, 2606.27880; LoRA on Meituan LongCat-Image-Edit; VTON+VTOFF+pose transfer; HRNet-W48 skeletons + Qwen2.5-VL instructions; **Apache-2.0**; weights HF); **Dress-ED** (2603.22607; project page only; NV).

**Two-stage vs direct — state of evidence.** (i) 2504.13078 is the explicit quantitative case for canonicalize-then-dress (less skin-colour leakage). (ii) MFP-VTON concedes "earlier P2P methods use an additional model to restore the standard garment" and offers direct mask-free DiT; **no cross-paper head-to-head with identical backbones found**. (iii) Canonical intermediates that are not flat images: **ViTon-GUN** (TVCG 31(10)) unwraps to an **A-pose garment representation** (flow + A-pose estimator) and plugs into pretrained garment-to-person diffusion with no retraining, arguing direct pose→pose warping "struggles to learn deformation"; **FW-VTON** (2507.16010) flatten→warp→integrate, releases P2P-VTON dataset. Code for both: NV.

## 2. Direct person-to-person / model-to-model transfer

- **MFP-VTON** (2502.01626) — target person + reference person; **mask-free**; DiT fine-tune with **Focus Attention loss** emphasising reference garment region and target non-garment region (attention-level leakage control). Triplets via outfit-swapping with a pretrained try-on net. Code NV. Ev: B.
- **RefTon** (Qihoo 360, 2511.00956, CVPR 2026) — target person (or agnostic) + flat garment + **optional reference person wearing it** (`--use_reference`). Worn: auxiliary detail reference (flat garment still primary). **FLUX.1-Kontext-dev** LoRA; "skips body parsing and warped masks". 360CVGroup/RefTon; LoRA HF qihoo360/RefVTON; VRF datasets; training code Mar-2026; **license not stated**; examples 8 GPUs, 1024×768 bf16. Ev: A/B.
- **Street TryOn** (WACV 2025) — tasks Street2Street, Model2Model, Model2Street, Shop2Street (DeepFashion2-derived 12,364/2,089; tops & dresses). Garment parsed from source (ATR), **DensePose warping + learned correction**, diffusion conditional inpainting. cuiaiyu/street-tryon-benchmark = dataset/annotations only, **method code not released**; non-commercial. Ev: A/B.
- **OmniVTON / OmniVTON++** (ICCV 2025; 2602.14552) — training-free on SD2-inp / SD1.5-inp / **Flux.fill**. Inputs: person, garment image (if missing, "extract it with a segmentation model" → worn refs via parsing crop), agnostic mask, TAPPS parsing, OpenPose, DensePose UV, pseudo-person via IMAGDressing(+ControlNet-Pose), CLIP-Interrogator prompts. Semantic-guided garment completion → pseudo-person → body-part matching → Structured Garment Morphing; DDIM inversion; ++ adds **Principal Pose Guidance** and dual-stream boundary refinement. Multi-human. **CC BY-NC 4.0**. VRAM/time not stated (heavy preprocessing). Ev: A/B.
- **CatVTON** — SD1.5-inp spatial concat; <8 GB @1024×768; abstract claims "in-shop **or worn** garments of any category"; MaskFree variant; CC BY-NC-SA. Leakage control for worn refs: none documented. Ev: A/B.
- **Oxygen-TryOn** (JD, 2607.21694) — explicit **M2M (item worn in the wild)** + C2M; mask-free; Qwen3-VL-8B + Wan-2.1 VAE + dual-stream MMDiT on JoyAI-Image-Edit; multi-item; text edits incl. pose. **Weights/inference not released** (Apache-2.0 repo). In-house usability 85.4% M2M (GPT-5 judge). Ev: A.
- **FASHN VTON v1.5** (2026-01) — maskless, pixel-space; garment input "model photos or flat-lay"; tops/bottoms/one-pieces; DWPose; bf16 Ampere+; Apache-2.0 repo (weights terms not stated); paper "coming soon". Ev: A.
- **OmniTry** (NeurIPS 2025) — FLUX.1-Fill-dev LoRA; mask-free; 2-stage training; 12 wearable classes; **≥28 GB bf16**; Apache-2.0; blurred-mask blend + repaint for boundaries. Worn refs NV. Ev: A/B.
- **JCo-MVTON** (DAMO, 2508.17614) — FLUX.1-dev MM-DiT, mask-free; person+garment+text; upper/lower/dress; Apache-2.0; worn refs NV. Ev: A.
- **Wear-Any-Way** (Alibaba, ECCV 2024) — single/multi-garment and **model-to-model**; sparse point control (roll sleeve, open coat, tuck). Code NV. Ev: B.
- **OutfitAnyone** — no code/weights; demo garment uploads only. Ev: A/B.
- **FitDiT** — DiT (SD3-class), garment-priors evolution, frequency-distance loss, **dilated-relaxed mask**; 1152×1536; 4.57 s/1024×768; non-commercial. Worn refs NV. Ev: A/B.
- **IDM-VTON** — SDXL + IP-Adapter, DensePose + agnostic; 768×1024; CC BY-NC-SA. Ev: A.
- **Leffa** — flow-field regularisation on attention; SCHP + DensePose; MIT code; ~6 s A100. Ev: A/B.
- **PromptDresser** — SDXL-inp; GPT-4o text; **prompt-aware mask** (tuck/fit); CC BY-NC-SA. Ev: A/B.
- Generation-centric (do not preserve A's photo): FashionComposer, DreamFit ("keep image" generator not open), MagicClothing, IMAGDressing (NC weights), StableGarment (no code). Poor fit.
- Minimal-condition DiTs: MC-VTON (FLUX.1-dev; 39.7M; 8-step), ITVTON, TED-VITON. Try-On-Adapter (outpainting — wrong direction). DiffusionTrend NV.

## 3. Multi-reference / front+back / detail
- **MV-VTON** (AAAI 2025): front and back garment images; **OpenPose left/right-arm positions decide front vs back**; Paint-by-Example base; weights released; MVG dataset by request; CC BY-NC-SA.
- **FastFit** (2508.20586): several items at once via cacheable reference-KV; SD1.5-inp; DressCode-MR; FastFit NC License.
- **RefTon**: one extra worn shot as detail reference.
- **Garments2Look** (CVPR 2026, 2603.14153): multi-reference outfit-level dataset incl. accessories — NV.
- **VTON 360** (2503.12165): any-view 3D try-on; claims preserving "collar accessories, line patterns, logos, texts, numbers".
- Detail/print modules: FitDiT frequency loss; TED-VITON text-preservation loss; Leffa attention-flow loss; **SIFT-VTON** (ICPR 2026; SIFT matches supervise cross-attention; StableVITON base; CC BY-NC-SA); **SPM-Diff** (ICLR 2025; semantic points + depth/normal cues); **DeCo-VTON** (ECCV 2026; decouples garment conditioning from denoising target; FID 4.44 vs Leffa 4.54 VITON-HD 512; weights CC BY-NC); UR-VTON refiner. **No dedicated "zoom-in/logo refinement" module found.**

## 4. Pose-adaptation mechanisms
**Explicit warping / UV.** Dense Pose Transfer (2018), **Pose with Style** (SIGGRAPH Asia 2021; DensePose UV coordinate completion with symmetry prior → StyleGAN2; **MIT**; `--part upper_body|lower_body|full_body|face`; DeepFashion 512), Lazova 360° textures, catalog→UV panels (2111.15140), Street TryOn. Documented weakness: UV warps "ignore the underlying 3D shape"; self-occlusion leaves large holes. Flow/TPS: GP-VTON, ClothFlow, FW-VTON, ViTon-GUN A-pose unwrapping, OmniVTON part-wise morphing, **FIA-VTON** (ICCV 2025; dense flow as attention guidance, "less sensitive to warp accuracy").
**Implicit attention.** Concat/in-context: CatVTON, TPD, MC-VTON, ITVTON, Voost, Any2AnyTryon (adaptive position embeddings), RefTon/MFP-VTON, OmniTry. Reference-net/adapter: IDM-VTON, TED-VITON, StableVITON. Correspondence-supervised attention: Leffa, SIFT-VTON, SPM-Diff.
**3D-aware.** 3DV-TON (keyframe 2D try-on → textured mesh via SMPL/GVHMR; MIT; textured-3D code pending), GS-VTON, VTON 360, SPM-Diff depth/normal cues.
**Behaviour under strong A/B pose difference:** MV-VTON: single-view methods fail when non-frontal. BooW-VTON: mask-based inpainting "introduces noticeable artifacts" under complex poses/occlusions. TEMU-VTOFF: occlusion/complex pose dominates try-off failure. ViTon-GUN: direct pose→pose warping fails → canonical pose. OmniVTON++: Principal Pose Guidance. **No paper benchmarks sitting / lying / foreshortened / arms-over-garment targets**; nearest proxies: StreetTryOn, VTBench hand-occlusion, OpenVTON-Bench. → **NV for hardest cases.**

## 5. Layering, add vs replace, skin/background occupation
- Mask-free (edit can exceed old footprint): **BooW-VTON** (CVPR 2025; pseudo-pairs from mask-based teacher; **try-on localization loss**; repo MIT but test-only, **no weights**; StreetVTON benchmark), CatVTON-MaskFree, MFP-VTON, OmniTry, JCo-MVTON, FASHN 1.5, Oxygen-TryOn, MF-VITON (2503.08650), FDM-MFVT (2606.29319), TAMF-VTON (2607.14807) — last three NV.
- Explicit layering: **Layering Virtual Try-On** (ECCV 2026, 2607.22924; `add` vs `swap` modes, text + optional DWPose; 512×896; weights/licence NV); **GO-MLVTON** (ICASSP 2026, 2601.13524; Garment-Occlusion Learning inner/outer; two upper layers, 512×384); Any2AnyTryon "try-on in layers".
- Mask strategies for extent change: TPD **Decoupled Mask Prediction** (denoises a latent mask conditioned on person+garment; mask = old ∪ new footprint; Paint-by-Example; NC), FitDiT dilated-relaxed mask, PromptDresser prompt-aware mask, Wear-Any-Way point control, 3DV-TON rectangular mask, OmniVTON CAT-DM agnostic.
- Skin generation: **UR-VTON** (2508.07680; training-free on Leffa; "undress then redress" for long→short; diagnoses "majority completion rule" — when most of the hole should be skin it is restored, when most should be cloth skin fails; code "upon acceptance"). Covering bare skin (long skirt over legs) is the easier direction per that analysis, but **no quantitative evidence specific to skirts over bare legs (NV)**.

## 6. Failure-mode literature
- Paste-back seams / unmasked drift: **ART-VITON** (2509.25749; VTON as linear inverse problem; StableVITON base; CC BY-NC-SA) names "abrupt transitions" at hard paste-back; VAE round-trip causes low-frequency colour shift visible only in inpainting (CVPR 2025 ASUKA decoder harmonisation); mitigations: blurred-mask blending (OmniTry, BrushNet), repaint-then-blend, dual-stream boundary refinement (OmniVTON++), PICS α-blending.
- Identity / body / category / detail drift: MuGa-VTON (2508.08488): tattoos, scars, accessories, fine body shape lost; GarDiff (2409.08258): "fidelity gap" on text/logos, CLIP lacks low-level features; 2504.13078: direct P2P transfers skin colour; BooW-VTON: masking destroys spatial/lighting info; UR-VTON: majority-completion bias; TryOffDiff: standard metrics cannot separate person vs garment quality → DISTS.
- Hand/arm occlusion: VTBench (2505.19571; hand-occlusion handling dimension).
- Preservation metrics / benchmarks: **OpenVTON-Bench** (2601.22725; ~100K pairs ≤1536², 20 categories; background / identity fidelity / texture / shape / realism; SAM3 + erosion separates boundary vs interior; Kendall τ 0.833 vs SSIM 0.611), Tstars-Tryon, VTONQA (2601.02945), VTEdit-Bench (2603.11734), FIT (2604.08526; 1.13M triplets with measurements), GO-MLVTON LACD.

## Practical takeaways (agent synthesis)
1. **Canonicalisation is the dominant 2025 answer** for worn refs: flat try-off (TryOffDiff-v2/MGT, TEMU-VTOFF, Voost, Any2AnyTryon) or A-pose unwrapping (ViTon-GUN) → then any mask-based try-on. Only 2504.13078 quantifies the benefit; downstream backbone NV.
2. **Direct worn-ref models with released weights:** RefTon (aux ref), CatVTON (claims worn input), FASHN 1.5 (model photos), OmniVTON/++ (via segmentation crop), JCo-MVTON/OmniTry (worn support NV); Oxygen-TryOn weights pending. Leakage control: attention losses (MFP-VTON, BooW) or parsing crops (OmniVTON, Street TryOn).
3. **Hard poses: no benchmark exists**; mask-free + pose guidance and 3D-aware guidance are the stated remedies, all B-level.
4. **Licensing:** permissive = Leffa (MIT code), OmniTry, JCo-MVTON, OrthoTryOn, FASHN repo (Apache), 3DV-TON, Pose-with-Style (MIT), IMAGDressing/DreamFit (Apache code, NC weights). NC = CatVTON, IDM-VTON, FitDiT, Voost, PromptDresser, TEMU-VTOFF, OmniVTON(++), MV-VTON, FastFit, TPD, SIFT-VTON, DeCo-VTON, ART-VITON. SSPL = TryOffDiff/MGT. No licence = TryOffAnyone, Any2AnyTryon.
